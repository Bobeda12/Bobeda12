## Projetos

### [Sinapse](https://github.com/Bobeda12/Sinapse)
Sistema de monitoramento e análise de editais de fomento usando NLP e Web Scraping.

Desenvolvido no IME para um problema concreto: pesquisadores perdendo oportunidades de financiamento por falta de tempo para acompanhar editais. O sistema rastreia o portal da FINEP, extrai e vetoriza os documentos com `sentence-transformers`, calcula a similaridade com as linhas de pesquisa cadastradas e dispara alertas automáticos por e-mail.

`Python` `Flask` `Scrapy` `Sentence-Transformers` `Scikit-learn` `SQLite` `Bootstrap`
