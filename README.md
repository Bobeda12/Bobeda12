## 🚀 Projetos em Destaque

### 🔬 [Sinapse](https://github.com/Bobeda12/Sinapse)
> Sistema de monitoramento e análise de editais de fomento à pesquisa usando NLP e Web Scraping

Desenvolvido na disciplina de IPE 2 no IME, o Sinapse automatiza o processo de busca e triagem de editais de financiamento (FINEP), aplicando **similaridade de cosseno** sobre embeddings gerados com `sentence-transformers` para identificar a aderência técnica entre chamadas públicas e linhas de pesquisa da instituição.

**Tecnologias:** Python · Flask · Scrapy · Sentence-Transformers · Scikit-learn · SQLite · Bootstrap

**Destaques:**
- 🕷️ Crawler automatizado que monitora o portal da FINEP
- 🤖 Motor de IA com embeddings multilíngues (`paraphrase-multilingual-MiniLM-L12-v2`)
- 📊 Dashboard web para visualização de scores de relevância
- 📧 Notificações automáticas por e-mail para editais de alta relevância
